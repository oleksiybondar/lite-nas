# GeoNames city data

`cities1000.zip` is the GeoNames cities1000 extract downloaded on 2026-10-28
from <https://download.geonames.org/export/dump/cities1000.zip>.

Copyright GeoNames contributors. Licensed under Creative Commons Attribution
4.0: <https://creativecommons.org/licenses/by/4.0/>. Data is provided as is.
The extract contains populated places with more than 1,000 residents and
administrative seats described in the GeoNames readme. Moments uses it for
offline, city-level reverse lookup; it does not claim street accuracy.
